## 全局纪律（每发提示词已内嵌，此处为备忘）

1. **引用逐条直达验真**（RD-024 纪律）：DOI 解析 + 标题比对，"给了 DOI 不等于真"；本库曾抓到把纯数学论文配给安全研究的错配。
2. **搜结果+场景，不搜概念**："refactor passed tests broke downstream"，不是 "software refactoring risk"。
3. **数字必须带样本量与出处原句**（M5）；C 级源（博客/转述）只能触发核实不能承重。
4. **不新增卡**：过程中发现的新坑只记一行候选，不展开。
5. 找不到就说找不到，附"已搜过什么、为什么判定没有"。

## 产出后的收尾流程（本机执行，两发用完回来跑）

1. 产出先过**出处核验**：逐条 doi.org/arXiv 直达，标题比对（本库三批核验累计抓过 4 处编号错配）；
2. 能升级的写成回写候选（目标卡 ID + 新 evidence.source 文案 + level），**只改 evidence/confidence 字段，不动触发词与正文结构**——动触发词要过 ⑰号门；
3. 入卡 → loadCards 校验 → selfcheck 全绿 → sync 八端；
4. 别忘了还压着一批没批的：**RD-025~028（消费级 AI 高风险建议批次）已验真待入库**，可以同批处理；
