# 核心卡评审记录 v1（2026-10-15，v0.5.7）

> 目的：让最核心的思想先生效——`priority: core` 的卡触发词权重 ×2（3→6）、同分优先排序。全库 77 张评审后 core 14 张（18.2%），各域均守 ≤20% 防通胀上限。

## 评审三维度

证据强度（empirical > 多源 case > 三源共识）× 跨领域性（是否所有任务都该先看）× 防御价值（拦得住多大的事故）。

## 落选说明（代表性）

- CODE-001 虚假不可能性（emp）：agent 失败榜第一，但「放弃类」失败在预检触发场景中较少命中——保留普通级，待真实使用数据复议；
- CODE-003 复跑不一致（emp）：已由 pass_k_relevant 机制另行承载；
- SEC-006 隐性串谋（emp）**从 core 调整为普通**：empirical 达标但场景窄（多 agent 博弈）；agent-security 域 20% 上限（6 张→1 张）下，普适性更强的 SEC-003（每个挂凭据的用户都命中）胜出。非降级证据质量，是排序取舍；
- SCI-005 准确率悖论：与 CODE-004/SCI-001 同属「好分数≠真对」簇，science 域名额给了证据更强的 SCI-001。

## 触发词变体维护

核心卡的高频口语变体必须覆盖（本轮补：CODE-004 += tests green/all tests/ship it/绿了/全绿；CODE-002 += ready to ship/任务完成/搞定了）。核心卡触发词缺失 = 最重要的思想没生效，CI 建议加变体覆盖抽检。
