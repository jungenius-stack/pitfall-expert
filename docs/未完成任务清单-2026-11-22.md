## 你要做的（按顺序）

### ① 配 npm token（10 分钟，能发 0.8.6）

1. 打开 https://www.npmjs.com/settings/jungenius/tokens
2. **Generate New Token** → 选 **Granular Access Token**
3. 填写：
   - Token name：`pitfall-stage-publish`
   - Expiration：90 天
   - **Packages and scopes**：选 **Only select packages** → 只勾 `pitfall-expert`
   - **Permissions**：`Read and write`
   - **勾上 `stage only`**
4. 生成后**先看 Summary**：必须显示 **"access to 1 package"**
   - 显示 "0 packages" = token 是废的，重做
5. 在终端执行（**别贴到对话里**）：
   ```bash
   npm config set //registry.npmjs.org/:_authToken=<你的新token>
   ```
6. 回来说一声，我跑发布

### ② 配 GitHub workflow 权限（5 分钟，能补 CI）

1. 打开 https://github.com/settings/tokens
2. 找到正在用的那个 token（**注意找对**，上次你改了但没生效）
3. 勾上 **`workflow`**
4. 保存
5. 跟我说一声，我推 CI 改动
