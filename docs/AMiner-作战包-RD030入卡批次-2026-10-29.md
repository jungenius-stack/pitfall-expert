[任务：给一张判断纪律卡找 LLM 侧实证证据] 我的卡讲「多量纲问题被单轴作答」：
用户问"A 和 B 哪个更好"，"更好"其实含多个独立维度（质量/成本/速度/风险…），
模型（或人）只挑一个维度答得斩钉截铁，结论自信但误导。请找可承重的实证研究：
- 检索方向：LLM comparative question answering evaluation dimension；
  pairwise evaluation LLM single criterion bias；multi-dimensional evaluation
  collapse large language model；LLM recommendation single attribute；
  decision quality AI assistant empirical study；human-AI comparative
  judgment dimension coverage
- 特别想要：①LLM 在比较/推荐类问题上维度覆盖不足的实证（有无量化：漏了几个
  维度/单维度占比）；②多维度结构化提示（如 MCDA 式拆解）是否改善 LLM 建议质
  量的对照实验
