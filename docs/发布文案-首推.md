## 一、从 REA（24 万星）拆出的 8 条推销结构

1. **仓库一句话 = 动词开头 + 范围承诺**。REA："Reverse engineer anything with agents, from app behavior down to native binaries."——不是"XX 是一个 YY 工具"，是"你能拿它干什么，从哪到哪"。
2. **首屏从读者的痛点瞬间开场，不是从产品开场**。我们照此把首句改成"你的 agent 说搞定了——迁移根本没成"。
3. **三拍能力句**：做什么 → 怎么做 → 产出什么证据。一段话说完，每拍不超过一行。
4. **英雄图 = 工具真实工作的截图**，不是 logo。**v0.7.8 起首选素材：终端里 `rm -rf` 被门控拦下的那一刻（截图或 GIF）——一张顶一千字**；次选真实三区报告节选。
5. **能力用大表呈现**（可扫读的广度证明）：目标 | 产出什么 | 前提。我们的"能防什么"表已是此结构，保留。
6. **战绩只用可核对的具体数字，拒绝形容词**。我们的对应物：引擎 29/29、良性语料 39 条零误拦、⑰号门 10/10 零增、三批文献核验抓 4 处引用错配。数字必须能追溯到 CHANGELOG/测试，没有就明说不承诺。
7. **信任三件套**：本地运行/零遥测（PRIVACY.md 可自行 grep 核验）、官方性声明（星多了再上）、"先更新再报错"纪律。
8. **社区循环**：showcase 征集 + 用户案例回流成新卡、署名进 source_ref（issue 模板四件套已就位）。

REA 没做的我们也别学的：徽章墙它没有；我们保留但克制（4 枚封顶）。

## 三、v0.7.8 Release Notes 草稿

**标题**：`v0.7.8 — Write-side interception: pit cards now carry machine-enforced rules`

**正文**：

```markdown
Your agent says "done" when it isn't — and when it finally runs `rm -rf`, force-pushes, or writes a real API key into a file, no report stops that. Reports rely on someone reading them.

This release moves enforcement into the tools themselves:

- **Pit cards now carry interception rules** (`intercept` field, structure-validated on load). CODE-006 ships 15 hard patterns — rm -r*, force push (**safe variants `--force-with-lease` / `--force-if-includes` are allowed**), `git clean -f*`, `find -delete`, `kubectl delete ns`, `aws s3 rm`, `UPDATE`/`DELETE` without `WHERE`, `mkfs`, `dd`, block-device writes — and CODE-027 blocks real secrets (`sk-`/`AKIA`/PRIVATE KEY/`ghp_`/`xox?`) **at write time**: the moment they hit the file, not in a later gitleaks scan. Add a card with rules, the gate learns a new danger.
- **Tiered gating** (fatigue-aware): deterministic rules block (exit 2); word-surface "high-risk card" matches only warn — measured on a real machine, a plain doc hit 9 of them, and warning that much trains you to ignore warnings.
- **39-command benign-corpus regression**: every hard rule ships with positive AND negative tests; safe variants are locked by tests. During development this immediately caught two regex bugs (`git push -f` missed; `echo "drop table"` false-blocked) — both fixed.
- Same local JSONL ledger for Claude Code (hooks) and DeepSeek Harness (cordis plugin), opt-in via `PITFALL_HOOK_LOG=1`. Zero telemetry by default — that's a PRIVACY.md hard promise, grep-verifiable.
- Card library now 125 across 7 domains, incl. hallucinated citations (GPT-4 refs still ~18% fabricated — Sci Rep 2023) and warning-fatigue blindness (~3 exposures to compliance decay).

Install: `sh install.sh` for skill + cards; the gate is one copy-paste registration step (hooks/README.md or dsh-plugin/README.md). `npx pitfall-expert "task"` once npm publish lands.

Honest bits: whether pre-task warnings actually reduce incidents is **unmeasured** — the only direct study is negative (CCS 2023), so we claim checking, not outcomes. Misses are forgivable; false "verified" is not. If a rule blocks something benign, the false-positive issue template turns it into a rule fix — credited.
```
