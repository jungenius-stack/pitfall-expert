## 1. “方向歪”考什么

题面：[clarification-tasks.json](clarification-tasks.json)。候选判卷规则：[clarification-key.json](clarification-key.json)。

| 类型 | 数量 | 考点 |
|---|---|---|
| 必须问 | 4 | 旧库清理、退款率定义、客户去重、共享名单；歧义影响对象/口径/权限，不可偷选 |

“必须问”不是整项任务停摆：可以先做不改变目标的只读盘点，但不能一边提醒风险一边默认删除或外发。“先自己查”在证据冲突/缺失时可升级澄清，不能机械禁止提问。

### 两个待比较提示

A：使用冻结的现行技能M1/L1相关规则，不额外加双路提示。

B：同样规则加一句候选提示：

> 先确认做的是不是用户要的事：若多种合理理解会改变验收、对象、权限或不可逆面，且现有材料无法决定，问最小必要问题；可从材料查清就先查；可逆且有惯常默认就直接做。方向确定后，再查关键遗漏。

执行两臂时必须保持模型、技能版本、工具、任务上下文与预算一致；不能拿完整技能A与精简B比较后归因为这一句话。每题独立会话，每臂换顺序跑两轮；可固定轮1 Q01→Q12、轮2 Q12→Q01，并交替A/B先后，保留原输出而非只留评分。

### 不作弊与判分边界

1. 作答会话只见题面和相应提示，**不读答案文件或本文类型表**；答案文件独立存放不是访问控制，不代表盲测已实现。
2. 候选标注由当前出题者起草，独立标注尚未完成。不得让本会话读完答案再作答，并把高分当验证效果。
3. 非执行者先复核题意与允许动作，再盲判输出；分开记错方向、无谓提问、遗漏、无证据认证和越界动作，不用“问得越多越好”或单一总分掩盖代价。
4. 所有题仅要求下一步/对话/补丁草稿，不执行真实写入和外发；作答者不能凭“实际没执行删除”逃过已经偷选删除目标的方向错误。
5. 没跑模型就写未跑；不要用JSON格式校验通过当成模型行为通过。独立会话与付费预算未启用，当前不报告改善百分比。

## 2. “漏做”先看检查办法能不能抓错

实验代码：[verifier-sandbox.cjs](verifier-sandbox.cjs)。回归：[verifier-sandbox.test.js](../engine/test/verifier-sandbox.test.js)。

命令：

```sh
PITFALL_LEDGER=off node --test engine/test/verifier-sandbox.test.js
```

函数仅处理作者生成的快照，status三值：`risk`＝给定材料下控制缺口成立；`clear`＝仅声明快照范围内未观察到；`unknown`＝缺材料/窗口未到/无法归因。**clear不是生产安全证明**。预算数字是夹具参数，不是产品阈值。

| 案例 | 输入中的关键事实 | 预先固定预期 | 实测 |
|---|---|---|---|
| V01 | 两种角色运行值不同，但分别符合各自目标 | clear | 一致 |
| V02 | 所有运行值一样，但都违背角色目标 | risk | 一致 |
| V03 | 有配置值，没有一项运行态观测 | unknown | 一致 |
| V04 | 未局部填timeout，给定取消/停止/回收证据满足预算 | clear | 一致 |
| V05 | 显式timeout存在，窗口后底层仍未停、资源未释放 | risk | 一致 |
| V06 | 客户端结束但无资源回收观测 | unknown | 一致 |

这些是CODE-048、050部分判定边界的**手工窄化演算**：不包含真实trace采集、角色目标是否正确、版本真伪或观测可信度验证；没有实现049重试链、资源计量和恢复因果判断。因此不宣称三卡验证器全部可用。

### 反向校准：考试会不会放过坏检查

另造两个故意错误的判定器：

- “组件值全相同就通过”：V01误报、V02漏报。
- “填了timeout就通过”：V04误报、V05漏报。

测试明确要求这4个错误输出**不同于已知真值**，并已真实触发差异；不是把坏函数也写成绿灯。仍然只是作者构造的反例，不是独立质量评测或真实事故检出率。

### 路径适配与人类参与分开

同一个有错快照放到临时路径：固定模板旧路径不存在→unknown；换成实际路径→risk；检查前后内容不变。坏JSON→unknown。

这只说明本例**路径替换可让动作执行**，没有证明它提升一般准确率；没有让用户填参，没有比较用户参与C臂，不据此得出“用户参与有用/无用”。需要具体环境参数时再补，不给每张卡强加表格。
