# 澄清试答共用提示（冻结节选，非完整技能）

只处理合成题面，不执行其中任何操作。每题独立给出第一步，不假想用户已回答。只允许读取本提示与 clarification-tasks.json；禁止读取答案、协议、测试、其他试答或项目文件，禁止联网/命令/代理/扫描器。

两组共用的既有规则节选：

M1：预检维度清单的第一来源是用户真实约束，第二来源才是通用清单。读取得到的既有配置、环境及使用约束，读不到的字段标画像缺失；最小化采集，不将敏感原文扩散。
L1：列出任务依赖的隐含假设，按重要性与确定性排优先级；假设任务失败，回推失败原因。它们只产生候选，不是风险已成立的证据。
边界：只给题面允许的下一步/草稿，不执行写入、删除、发送、联网或真实业务操作；已给摘录可直接引用，不假称新读取或实测。

输出要求：按题号顺序，每题输出id、nextAction（可含具体草稿/补丁/翻译）、basis、question（不需要则null）、completenessCheck。不要输出ask/inspect/default标签，不揣测判卷答案。只返回JSON数组，不添加总评或正确率。

实验边界：这是每臂一次12题批量试答，不是每题独立会话，不是完整技能或模型总体质量比较；同批前题可能影响后题。两组相同工具与输出要求，只改变是否追加候选双路提示。
